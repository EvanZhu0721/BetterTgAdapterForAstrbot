# Telegram 流式空行分段

让 AstrBot 在 Telegram 群聊中按空行或自定义分隔符发送多条消息，每段仍保留流式更新。支持跨文本块匹配，代码围栏内不拆分；私聊和其他平台不受影响。无额外模型调用。

## 安装

在 AstrBot 插件页通过本 GitHub 仓库地址安装，或上传插件 ZIP。保持 AstrBot 的“流式输出”开启，再启用本插件。

## 配置

进入“插件 → Telegram 流式空行分段 → 配置”。保存后重载插件，每条流开始时读取配置。

- **按空行分段**：默认开启，可关闭，无需手写正则。
- **自定义分隔符列表**：逐项填写字符，插件自动转为正则匹配；例如 `。`、`---`、`\n`（单换行）、`\r\n`。最多 32 项，每项 1–64 字符；重叠时优先最长项。
- **保留自定义分隔符**：默认开启，将命中文字留在上一段末尾；关闭则移除。连续分隔符合并为一次边界；内置空行规则不保留空行。
- **高级分隔正则**：可选，例如 `[。！？]{1,3}`、`---|===`。只支持最大宽度不超过 64 的非空简单模式；无界 `*`/`+`、锚点、断言、反向引用及复杂重复不支持，无效项会记录日志并忽略。高级匹配可能稍延迟流式更新。

| 选项 | 默认 | 范围 |
| --- | --- | --- |
| 新消息最小间隔 | 3.2 秒 | 0.1–60 秒 |
| 发送与编辑共享最小间隔 | 1.1 秒 | 0.1–60 秒 |
| 限流等待额外余量 | 0.1 秒 | 0–10 秒 |

非法值回退默认。同群回复依次发送；调小间隔可能更频繁限流，Telegram 指定的等待时间始终保留。可通过 `enable` 关闭。

## 兼容性

已在 AstrBot v4.28.0-beta.1 测试。插件包装内部发送接口，升级 AstrBot 后需验证兼容性。混合图片等组件的文本块整体透传；已结束段落可能显示 Markdown 原始标记。限流等待会降低更新速度，非 429 错误仍由核心处理。

测试：使用 AstrBot 的 Python 环境，在仓库目录运行 `python -m unittest discover -v`；必要时将可选环境变量 `ASTRBOT_ROOT` 指向 AstrBot 源码根目录。未安装 AstrBot 时跳过集成测试。
